Katam Virtualization

An open-source virtualization platform for x86-64 servers. KVM virtual machines, Ceph storage, software-defined networking with micro-segmentation, HA with fencing, DR, and a web UI and API over all of it.

What you need

  • x86-64 servers with Intel VT-x/VT-d or AMD-V/AMD-Vi (Dell, HPE, Lenovo, Supermicro, Huawei and others).
  • One server for a lab (all-in-one), or three or more for Ceph storage, HA and live migration.
  • An OS disk per server (a RAID 1 mirror is ideal) and, for Ceph, empty data disks in HBA/JBOD mode.
  • A small VM or box for the controller (2 vCPU, 4 GB RAM) unless you use all-in-one.

Install in five steps

  1. Prepare firmware. Enable VT-x and VT-d (Intel) or SVM and IOMMU (AMD). Turn Secure Boot off on the host.
  2. Boot the ISO from a USB stick (dd, Rufus or balenaEtcher) or the BMC's virtual media (iDRAC, iLO, XClarity, iBMC).
  3. Answer the installer: role (node, controller, all-in-one or witness), the OS disk, the management network, and an admin account. It installs without internet access.
  4. Join nodes to the controller. On each node: 
    sudo katam-node-setup --controller-key "ssh-ed25519 AAAA... katam@controller" \
  --controller-ip <controller-ip> --peers "<node storage IPs>"
    The controller's key is in /var/lib/katam/.ssh/id_ed25519.pub on the controller.
  5. Sign in. Edit /etc/katam/config.yaml on the controller to list your nodes, storage and networks, run sudo systemctl restart katam, then open http://<controller-ip>:8080. The first admin password is in /root/katam-initial-admin.txt.

For three or more nodes, set up Ceph with /usr/share/katam-node/ceph-bootstrap.sh on the first node; it prints the settings to paste into config.yaml.

Install several servers unattended

Press e on the first boot menu entry, add parameters to the end of the linux line, then press Ctrl+X:

katam.auto=1 katam.role=node katam.disk=/dev/sda katam.iface=eno1
katam.ip=172.20.10.11/24 katam.gw=172.20.10.1 katam.dns=172.20.10.1
katam.hostname=hv1 katam.password=Change-Me-Now

Anyone with BMC console access can read boot parameters, so change the password after installing.

Updates

Installed servers receive new versions from a signed apt repository. When a release is out, admins see a banner in the Katam UI with an Upgrade nodes button that upgrades nodes one at a time, moving VMs away first. Upgrade the controller with sudo apt update && sudo apt upgrade.

Status

Katam is early software (0.x). The installer, web UI, API, access control, image import/export, HA restart and metering have been tested. Ceph, OVN networking, BMC fencing, DR mirroring and directory sign-in follow standard tooling but have had limited testing on real hardware. Try it in a lab before trusting it with production workloads, and keep backups.
